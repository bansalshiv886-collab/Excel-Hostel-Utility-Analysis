# Excel-Hostel-Utility-Analysis
An interactive Excel dashboard built to monitor and analyze electrical energy consumption across a residential hostel facility. The dashboard tracks key parameters — active power, reactive power, voltage, and current intensity — across three sub-metering zones over an 8-month period.
This project is an interactive Hostel Utility Monitoring Dashboard built entirely in Microsoft Excel, using real-world electrical consumption data sourced from Kaggle (Individual Household Electric Power Consumption Dataset). The dataset contains over 2 million minute-level readings collected from a single household, which were aggregated and analyzed to simulate a hostel utility monitoring system.
The dashboard tracks and visualizes seven key electrical parameters — Global Active Power, Global Reactive Power, Voltage, Global Intensity, and three Sub-Metering zones — across an 8-month monitoring window (late 2006 – mid 2007). Using Pivot Tables, Pivot Charts, Power Query, and interactive Slicers, the dashboard delivers six dynamic visualizations filterable by Month, Day, and Hour, enabling drill-down analysis at any time granularity.
Key highlights include identification of peak demand windows (6–9 AM and 5–10 PM), Sub_metering_3 dominating 43% of total consumption, stable voltage readings between 230–255V confirming grid reliability, and clear seasonal demand spikes in winter months. The project demonstrates end-to-end data analytics skills — from raw data ingestion and cleaning to insight-driven visual storytelling — making it a practical tool for energy auditing and facility management decision-making.
